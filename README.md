## アメリカ美術_名画と芸術家
https://yuspovgagalin.github.io/America-knowledge/america-bowl-アメリカ美術.html
- `メトロポリタン美術館の名作（Q1〜Q14）：`『デラウェア川を渡るワシントン』（ロイツェ）、『メキシコ湾流』（ホーマー）、『マダムX』（サージェント）、『オックスボウ』（コール）など、The Met所蔵の代表作を画像付きで学べます。肩ひもが起こしたサロンのスキャンダル、詩から生まれた『黄金の数字の5』、大統領執務室にも置かれた『ブロンコ・バスター』などの由来を押さえます。
建国期の絵画と大風景画（Q15〜Q26）：2ドル紙幣裏面の『独立宣言』が実は「署名」ではなく「草案提出」の場面であること、1814年に救い出されたワシントンの肖像、実話のサメ襲撃を描いた『ワトソンと鮫』のほか、ハドソンリバー派（コール、デュランド、チャーチ）と西部の大風景（ビアスタット、モラン）を整理できます。イエローストーン国立公園誕生と絵画の関係も扱います。
- `肖像・人物画と海を渡った画家（Q27〜Q39）：`パリやロンドンで活躍したホイッスラー、サージェント、カサットが中心です。『ホイッスラーの母』の所蔵先（オルセー美術館）、ラスキンとの「絵の具の壺」裁判、浮世絵がカサットに与えた影響、ベラスケスに学んだ『ボイトの娘たち』、エイキンズ『グロス・クリニック』、タナー『バンジョー・レッスン』などを網羅しています。
- `写実・都市・モダニズム（Q40〜Q50）：`ホーマーの海と田舎の情景、ニューヨークの庶民を描いたアシュカン派（ベローズ、スローン）、『アメリカン・ゴシック』のモデルが妹と歯医者だった話、ホッパー『ナイトホークス』と映画『サイコ』の屋敷のモデルになった『線路わきの家』、マディソン・スクエア・ガーデンの風見だった彫刻『ディアナ』などを学べます。
- `ビジュアル図鑑（作品50点）：`全作品の画像・作家・制作年・所蔵先と「何を描いているか」のうんちくを日本語で一覧できます。作家別・分野別の絞り込み付き。
- `作家一覧（28人）：`各作家の生没年、人物紹介、収録作品を表で確認できます。作品名を押すとその作家の作品だけを図鑑に表示します。
